# React 全局确认对话框 (Confirm) 组件文档

> 实现位置：`src/component/ui/confirm-dialog.jsx`；本目录 `layout.jsx` 只是同名门面。样式为 Tailwind 工具类，颜色一律走 `src/global.css` 的语义令牌：遮罩是 `bg-black/50`（v4 无模糊），卡片是 `bg-background` + `border-border` + `shadow-lg`，标题 `text-foreground`、正文 `text-muted-foreground`；出入场用 `tw-animate-css` 的 `animate-in/out fade-in-0 zoom-in-95` 工具类。按钮与输入框直接用库里的 `Button` / `Input`。这里刻意不用受控 open 模型的对话框库：`confirm.hide()` 由外部命令式调用、卸载要挂在出场动画结束上，那种模型没有对应出口。

## 概述

基于 React 的命令式 API 确认对话框组件，支持全局调用和现代化动画效果。

## 功能特性

-  全局调用：任意 JS 模块均可触发
-  灵活内容：支持文本/自定义组件
-  输入支持：可选输入框功能
-  现代化设计：毛玻璃卡片 + 入/出场动画
-  回调处理：`onConfirm`/`onCancel`
-  交互友好：点击遮罩可取消
-  Portal 渲染：避免样式干扰
-  样式：Tailwind 工具类（类名里写的是字面色值），无 CSS Module

## 安装配置


在任何 JavaScript 文件中导入并使用 `confirm` 对象：

#### 基础用法：

```Jsx
import { confirm } from '@/component/confirm/layout';
function handleClick() {
  confirm.show({
      title: '确认删除',
      content: '您确定要删除这条记录吗？删除后将无法恢复。',
      onConfirm: () => {
      console.log('用户点击了确定');
      // 执行删除逻辑
      },
      onCancel: () => {
            console.log('用户点击了取消');
      }
  });
  }
```
#### 带输入框的用法：

```Jsx
import { confirm } from '@/component/confirm/layout';
function handleRename() {
  confirm.show({
        title: '重命名文件',
        content: '请输入新的文件名：',
        showInput: true,
        inputPlaceholder: '例如：report.docx',
        inputDefaultValue: '旧文件名.txt',
        onConfirm: (fileName) => {
        if (fileName) {
            console.log(`新的文件名是: ${fileName}`);
        // 执行重命名逻辑
        } else {
           console.log('用户没有输入文件名。');
        }
        },
  });
  }
```

#### 自定义输入框
```Jsx
const CustomContent = () => (
    <div>
    <h3>自定义区域</h3>
    <p>使用任何React组件作为内容</p>
    </div>
);

confirm.show({
  title: "自定义对话框",
  children: <CustomContent />
});

```


## API 参考

### `confirm.show(config)`

显示确认对话框。
### confirm.show(config)

| 参数              | 类型      | 默认值                 | 说明           |
| ----------------- | --------- | ---------------------- | -------------- |
| title             | string    | "提示"                 | 对话框标题     |
| content           | string    | "确定要执行此操作吗？" | 正文内容       |
| children          | ReactNode | null                   | 自定义组件内容 |
| showInput         | boolean   | false                  | 是否显示输入框 |
| inputPlaceholder  | string    | ""                     | 输入框占位文本 |
| inputDefaultValue | string    | ""                     | 输入框默认值   |
| onConfirm         | Function  | () => {}               | 确认回调       |
| onCancel          | Function  | () => {}               | 取消回调       |
|     showCancel| Boolean |false | 是否单列即不显示取消 |

### confirm.hide()

手动关闭对话框

## 实现原理

- **命令式调用**：`React.createRef` + `useImperativeHandle` 把 `show` / `hide` 交给模块级的 `confirm` 对象。
- **状态管理**：`useState` 管配置与可见性，配置为 `null` 时整个浮层不渲染。
- **Portal 渲染**：`createPortal` 渲染到 `document.body`，避免受父组件样式影响。
- **动画与卸载**：卡片与遮罩各带一条入/出场动画，`hide()` 只把可见性置为 false，真正卸载认卡片自己的 `animationend`。这里有两道保险：事件里 `e.target !== e.currentTarget` 直接忽略（后代自己播完动画会冒泡上来冒充结束），另加一个 400ms 定时器兜底，动画掉帧或被系统"减弱动态效果"挡掉时遮罩也不会卡在页面上。

## 最佳实践

`confirm.show()` 没有返回值，结果只从 `onConfirm` / `onCancel` 回调给出：

```jsx
function handleSubmit() {
  confirm.show({
    title: '提交数据',
    content: '确定提交当前表单吗？',
    onConfirm: async () => {
      await api.submit();
    },
  });
}
```

需要外部主动收起时调 `confirm.hide()`——它走完出场动画再卸载，不会把遮罩留在页面上。
