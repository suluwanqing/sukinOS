# DateGoogle 日历组件使用指南

> 实现位置：`src/component/ui/date-picker.jsx`；本目录 `layout.jsx` 只是同名门面。样式为 Tailwind 工具类，颜色一律走 `src/global.css` 的语义令牌，且面板是**自包含**的：`rounded-lg border-border bg-popover text-popover-foreground shadow-lg`。原先整套色值（白字、半透明白底、白色 inset 环）依赖「日历铺在有底图的深色玻璃面板上」这个未声明的前提，而挂它的容器样式里并没有背景色，导致同一组件在不同上下文长得不一样。日期格四态互斥：选中 `bg-primary text-primary-foreground`、今日 `border-border bg-accent`、月内 `text-foreground` 加 hover 到 accent、月外转 `muted-foreground` 低透明度。

```jsx
import DateGoogle from '@/component/date/google/layout';
```

| prop | 默认值 | 说明 |
| --- | --- | --- |
| initialDate | new Date() | 初始选中日期 |
| onDateChange | - | `(date) => void`，选中日期变化时触发（含首帧） |
| className | '' | 追加在根节点上的类名 |

周一为一周起点；跨月补位的日子置灰但可点击，点击后自动翻到该月。
