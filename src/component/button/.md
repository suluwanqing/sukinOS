# button组件

## 概述
常规按钮组件。真身在 `src/component/ui/button.jsx`（cva 变体 + Tailwind 工具类），本目录只留一层同名门面；不再依赖 BEM 类名与 CSS Module。


## 基础用法

最简单的用法是直接引入并使用 `Button` 组件。

```jsx
import Button from '@/component/button/layout'

function MyComponent() {
  return <Button>默认按钮</Button>
}
```
## Props
组件接收以下属性进行配置：

| 参数           | 说明                                                                | 类型                                                                                    | 默认值      |
| :------------- | :------------------------------------------------------------------ | :-------------------------------------------------------------------------------------- | :---------- |
| `children`     | 按钮的显示内容，可以是文本或任何 React 节点                         | `React.ReactNode`                                                                       | `-`         |
| `variant`      | 造型档，决定按钮的表面色                                            | `string` <br/> `'default'`, `'dark'`, `'outline'`, `'secondary'`, `'ghost'`, `'destructive'`, `'link'`, `'success'`, `'warning'`, `'info'` | `'default'` |
| `type`         | 旧造型轴，仅作 `variant` 的别名映射：`primary`/`dark`/`danger`/`success`/`warning`/`info`/`default`→`outline`、`text`→`ghost`。**不会透传成 DOM 的 `type`**，写 `submit` 无效（组件恒发 `type="button"`） | `string` | `-` |
| `size`         | 尺寸档：`'default'`(h-9) `'sm'`(h-8) `'lg'`(h-10) `'xs'`(h-6) `'icon'`(36) `'icon-sm'`(32) `'icon-lg'`(40) `'icon-xs'`(24)；旧名 `'large'`/`'medium'`/`'small'`/`'mini'` 仍映射得到。≤767px 时桌面档 <36px 的抬到 36px 触控下限（`xs` 徽标档除外） | `string` | `'default'` |
| `plain`        | 是否为朴素按钮（背景透明，带边框）                                  | `boolean`                                                                               | `false`     |
| `round`        | 是否为圆形按钮                                                      | `boolean`                                                                               | `false`     |
| `block`        | 是否撑满父容器宽度                                                  | `boolean`                                                                               | `false`     |
| `disabled`     | 是否禁用按钮                                                        | `boolean`                                                                               | `false`     |
| `loading`      | 是否显示加载中状态（会覆盖 `icon` 并禁用按钮）                      | `boolean`                                                                               | `false`     |
| `focus`        | 键盘聚焦时是否把描边换成 `--ring`。放在不需要焦点提示的场景（如工具条、纯视觉控件）时传 `false`，描边保持常态色 | `boolean` | `true` |
| `hover`        | 鼠标悬浮时是否加深底色。传 `false` 时整表悬浮反馈不发，底色保持常态（`plain` 的淡底也一并去掉）；触屏设备本身不触发悬浮 | `boolean` | `true` |
| `icon`         | 自定义图标，可以传入一个 React 组件（如 SVG 组件）                  | `React.ReactNode`                                                                       | `-`         |
| `iconPosition` | 图标显示位置                                                        | `string` <br/> `'left'`, `'right'`                                                      | `'left'`    |
| `asChild`      | 把样式套给唯一子元素而不是渲染 `<button>`，用于做链接式按钮          | `boolean`                                                                               | `false`     |
| `className`    | 额外的自定义类名，经 `cn`（clsx + tailwind-merge）合并，同族工具类以传入者为准，不必写带 `!` 的强压类；业务侧不许裸写 Tailwind 类名（`global.css` 的 `@source` 只扫 `src/component`），宽度/几何请走 CSS Module 类 | `string` | `''` |
| `...restProps` | 接受除上表以外的原生 `<button>` 属性，如 `onClick`, `name`, `title` | `React.ButtonHTMLAttributes`                                                            | `-`         |

`dark` 与 `default` 的区别只在表面令牌：`default` 用 `--primary`，`dark` 用 `--foreground`（墨面，两档模式自适应反色），与 `Check` 的 `type='dark'` 同源。仓库是 neutral 皮，亮色档两者都呈近黑，深色档都反成浅面；要"恒定的黑"请自己评估是否真的需要，不要用内联 `style` 覆盖底色——那会在深色档留下深字压黑底。

按钮内图标会被基串统一压到 16px（除非图标自带 `size-*` 类名，而业务侧不许写裸类名），所以尺寸请由调用方给：`icon={<SearchIcon size={16} />}`。
