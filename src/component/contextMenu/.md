# 包裹组件 contextenu

> 实现位置：`src/component/ui/context-menu.jsx`——已整体迁移到 Radix ContextMenu 原语，本目录 `layout.jsx` 只是同名门面。颜色一律走 `src/global.css` 的语义令牌：面板是 `bg-popover` + `text-popover-foreground` + `rounded-md` + `shadow-md`，菜单项 `rounded-sm` + `focus:bg-accent`，分隔线 `bg-border`；危险项走 destructive 变体，禁用项由 `data-[disabled]` 系列接管。原先那套「单例管理器 + 自建 body 宿主 + 手算坐标」已移除——Radix 的 Portal 与指针定位原生解决了 transform 包含块问题，且 Radix 明确不支持在用户交互前把 `open` 置 true（那样锚点不确定）。对外 API（`menuItems` / `metaInfo` / `onShow` / `onHide` / `className`）与数据形状完全不变。类名，所以外观不随祖先主题翻。

## 概述

这是一个用于,右键菜单的功能使用。全局只有一个挂在 `body` 上的宿主容器，触发器组件只负责把这次右键的数据交给它。

## API 参考
| Prop        | 类型      | 必需 | 默认值     | 描述                                                |
| :---------- | :-------- | :--- | :--------- | :-------------------------------------------------- |
| `children`  | ReactNode | 是   | -          | 需要附加右键菜单的单个子组件。         |
| `menuItems` | Array     | 是   | `[]`       | 一个对象数组，用于定义菜单的结构和行为。|
| `onShow`    | Function  | 否   | `(metaInfo) => {}` | 菜单显示时触发的回调函数,参数是传输的metaInfo。             |
| `onHide`    | Function  | 否   | `(metaInfo) => {}` | 菜单隐藏时触发的回调函数,参数是传输的metaInfo。              |
| `className` | String    | 否   | `''`       | 应用于菜单根元素的额外 CSS 类名。        |
|`metaInfo`|    any | 否 | - | 如果需要使用渲染数据项的数据可传输|

## 实现原理
ContextMenu(触发器) → 模块级单例(容器 + root + 状态) → MenuHost(渲染宿主)

```javascript
let state = { visible: false, payload: null };
const listeners = new Set();

const manager = {
  ensureHost() {
    // 容器还在 DOM 里就复用，被外部清掉则重建
    if (this.root && document.body.contains(this.container)) return;
    this.container = document.createElement('div');
    this.container.id = 'context-menu-host-container';
    document.body.appendChild(this.container);
    this.root = createRoot(this.container);
    this.root.render(<MenuHost />);
  },
  show(payload) {
    this.ensureHost();
    // 菜单宽高按 200/300 估算，先用视口把坐标收进来再写状态
    publish({ visible: true, payload: { ...payload, position } });
    payload.onShow?.(payload.metaInfo);
  },
  hide() {
    // 没在显示就直接返回；否则写状态并回调 onHide(metaInfo)
  },
};
```

`MenuHost` 用 `useState(state)` 读初始快照，再在 `useEffect` 里把自己注册进 `listeners`。首次右键时状态在宿主挂载之前就已写好，组件挂载直接读到可见——所以旧实现中 manager 与 host 之间的 `onReady` 握手、以及 `setTimeout(..., 0)` 补一拍都删掉了。

关闭途径：点击菜单外、Esc、页面滚动，以及触发器卸载时补一次 `hide()`（只关自己打开的那次，不会误关别人的菜单）。

## 定位方式

面板坐标是手算的 `position: fixed` + 自建 body 容器，没有用定位浮层库：窗口外壳带 `transform`，会把 fixed 的包含块改写成窗口本身，那类库在这种环境里定位会偏。

## 注意事项

- icon 传 `src/component/ui/icons.jsx` 名字表里的键（历史字体图标名，如 icon-a-document），也可直接传一个已渲染的节点；表里没有的名字渲染为空
- 多次渲染在一个组件内,同样需要符合key来进行处理
- 如果是嵌套的,你正常使用即可,因为他毕竟是单例的,会自动处理为传入的menuItem
- isNext事件:[需要确认环节] 只有一个参数参数是点击项数据[非DOM]
- 非isNext事件:[无需确认环节] 只有一个参数,是右键时传入的metaInfo[不会传播event]
- 所有事件返回:返回当前传入的metaInfo项[不会传播event]
