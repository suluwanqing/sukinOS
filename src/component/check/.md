# Check 开关组件文档

> 实现位置：`src/component/ui/switch.jsx`（自绘轨道与滑块的 div + Tailwind 工具类，颜色走 `src/global.css` 的语义令牌）；本目录 `layout.jsx` 只是同名门面。

## 概述

这是一个可定制的开关切换组件（Toggle/Switch），支持三种尺寸、交互模式（标准/圆点）以及视觉风格（药丸/简约边框/暗黑）。轨道与滑块都是本组件自绘的 `div`/`span`，`role="switch"`、`aria-checked`、`tabIndex` 由自己挂，空格与回车走 `onKeyDown`。样式由 Tailwind 工具类驱动，类名合并走 `cn()`。

**默认就是药丸形（`rounded-full`）**，与官网 Switch 一致；`round` 因此是个冗余的历史 prop，只在显式传 `false` 时才落到 radius 刻度的 `rounded-md`。

配色只有两支：`type="dark"` 走反色表面（选中 `bg-foreground`、未选中 `bg-background` + `border-input`），其余所有 type 一视同仁——选中 `bg-primary`、未选中 `bg-input`。原先除 dark 之外的所有 type 都落到同一支 `--su-purple-400`，于是 `primary` / `success` / `danger` 这些名字不同的档位长得一模一样。

## 功能特性

- **多模式交互**：支持标准滑块模式和 Dot（圆点）模式
- **丰富的尺寸**：提供大、中、小三种预设尺寸
- **视觉风格**：默认药丸形，支持 plain（简约边框）和 dark（反色表面）两种变体
- **状态管理**：完备的 disabled（禁用）状态支持
- **无障碍支持**：内置 aria-checked 和 role="switch" 属性

## 基础用法

最简单的用法是直接引入并使用 Check 组件。


```jsx
import React, { useState } from 'react';
import Check from '@/component/check/layout';
  function MyComponent() {
    const [checked, setChecked] = useState(false);
    return (
    <Check
      checked={checked}
      onChange={setChecked}
      round // 可省略：默认就是药丸形；传 false 才会变成方角
    />
  );
}

```

## Props API 参考

| 属性名    | 说明                                | 类型                       | 可选值                                                               | 默认值    |
| --------- | ----------------------------------- | -------------------------- | -------------------------------------------------------------------- | --------- |
| checked   | 开关当前的开启/关闭状态             | boolean                    | -                                                                    | false     |
| onChange  | 状态变化时的回调函数                | (checked: boolean) => void | -                                                                    | -         |
| type      | 主题类型                            | string                     | 只有 `dark` 另有整套反色表面；其余取值（`default` / `primary` / `success` / `danger` / `warning` / `info` / `violet` / `muted`）激活态一律 `bg-primary` | 'default' |
| size      | 开关物理尺寸                        | string                     | 'large', 'medium', 'small'                                           | 'medium'  |
| dot       | 是否开启圆点交互模式           | boolean                    | -                                                                    | false     |
| round     | 是否开启全圆角（药丸形状）          | boolean                    | 不传或传 `true` 都是药丸（默认即药丸）；传 `false` 才落到 `rounded-md` | 不传（药丸） |
| plain     | 是否为简约风格（透明背景+带色边框） | boolean                    | -                                                                    | false     |
| disabled  | 是否禁用交互                        | boolean                    | -                                                                    | false     |
| className | 额外的自定义 CSS 类名               | string                     | -                                                                    | ''        |
| style     | 自定义内联样式                      | React.CSSProperties        | -                                                                    | -         |
