# Page 分页组件使用指南

> 实现位置：`src/component/ui/pagination.jsx`；本目录 `layout.jsx` 只是同名门面。样式为 Tailwind 工具类（类名里写的是字面色值），已不再依赖 CSS Module 与 BEM 类名。

```jsx
import Page from '@/component/page/layout';
```

| prop | 默认值 | 说明 |
| --- | --- | --- |
| total | 0 | 总条数 |
| pageSize | 10 | 每页条数（非数字时回落 10） |
| current | 1 | 当前页 |
| sizeOptions | [10, 20, 50, 100] | 每页条数候选，渲染为 `Select` |
| showElevator | true | 是否显示「跳转至 N 页」 |
| showTotal | true | 是否显示总条数 |
| scrollTo | 'top' | 翻页后滚动位置：`'top'` / `'bottom'` / 其它值不滚动 |
| onPageChange | () => {} | `(page) => void`，页码已被钳制在 1..totalPages |
| onPageSizeChange | () => {} | `(size) => void` |
