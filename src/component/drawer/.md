# Drawer 组件

> 实现位置：`src/component/ui/drawer.jsx`；本目录 `layout.jsx` 只是同名门面。样式全部走 Tailwind 工具类，不依赖 CSS Module 与 BEM 类名。

贴边抽屉：一层遮罩 + 从宿主容器某条边滑入的面板，用来装导航、筛选、目录这类次要但随时要用的内容。

1. **铺在最近的定位祖先里**：不传送、不固定到视口，所以只盖住宿主容器本身，不会压住状态栏与其他窗口；应用自带的 CSS Modules 作用域对它依然有效。宿主容器要自己占住位置与高度。
2. **常驻挂载**：收起态把面板整条推出容器，由根节点裁剪藏住，进出场共用同一棵 DOM。面板里放长列表、图表都不会因为开关而重新挂载。
3. **触控优先**：点遮罩与按 Esc 都走 `onClose`；关闭叉由 `showCloseButton` 控制，默认不出现，因为多数抽屉的收起靠遮罩就够。移动端关闭叉自动抬到 36px 见方。
4. **主轴尺寸只有一个入口**：`size` 按 `side` 落到宽或高，缺省值同样由贴边方向推导（左右取 `min(232px, 78%)`，上下取 `min(240px, 60%)`），不开第二个尺寸开关。侧向档按导航抽屉的实际内容宽度定：现有六处导航侧栏最宽 220px，再宽就是留白而不是信息。

## Props（Drawer）

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| ------ | ---- | ---- | ------ | ---- |
| open | Boolean | 是 | false | 显隐，受控 |
| onClose | Function | 是 | - | 点遮罩、按 Esc、点关闭叉时回调 |
| side | String | 否 | 'left' | left / right / top / bottom；清单外的值按 left 渲染 |
| size | Number / String | 否 | 按 side 推导 | 主轴尺寸，数字按像素处理 |
| label | String | 否 | - | 面板的无障碍标签，读屏用 |
| showCloseButton | Boolean | 否 | false | 面板右上角的关闭叉 |
| className | String | 否 | - | 透到面板本身，改底色、内边距走这里 |
| style | Object | 否 | - | 透到面板本身，优先级高于 `size` |
| children | ReactNode | 否 | - | 面板内容 |

> 宽高请走 `size`：内联尺寸优先于 `className` 里的宽度类，写在 `className` 里的宽度会被盖住。

## 子部件

都是往面板里摆的普通块，不给也不影响使用。

| 名称 | 说明 |
| ---- | ---- |
| DrawerHeader | 顶部标题区，不参与滚动 |
| DrawerTitle / DrawerDescription | 标题与一句话说明，放在 Header 里 |
| DrawerBody | 中间滚动区，占满剩余高度 |
| DrawerFooter | 底部操作区，贴在面板另一端 |

## 用法

```jsx
const { Drawer, DrawerHeader, DrawerTitle, DrawerBody, DrawerFooter, Button } = AppSDK.Components;

export default () => {
  const [open, setOpen] = useState(false);
  return (
    <div style={{ position: 'relative', height: '100%' }}>
      <Button onClick={() => setOpen(true)}>打开导航</Button>
      <Drawer open={open} onClose={() => setOpen(false)} side="left" label="导航">
        <DrawerHeader>
          <DrawerTitle>导航</DrawerTitle>
        </DrawerHeader>
        <DrawerBody>列表内容</DrawerBody>
        <DrawerFooter>
          <Button onClick={() => setOpen(false)}>完成</Button>
        </DrawerFooter>
      </Drawer>
    </div>
  );
};
```

## 与官方 Sheet 的差异

官方 Sheet 把面板传送到文档根节点、按能力换 DOM（窄屏挂成抽屉、宽屏挂成侧栏），并靠动画类在卸载时播退场。这里三点都反着来，原因是宿主环境不同：

- 不传送——传送出去就落在 CSS Module 作用域之外，应用自带样式全丢；
- 不换 DOM——抽屉里装的是各应用自己的侧栏组件，重挂代价高，`side` 一个属性就能表达四种形态；
- 不靠动画类——动画类在常驻挂载的节点上会在首帧就播退场，改用位移过渡，进出场对称。
